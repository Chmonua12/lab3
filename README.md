## Реализация коллекций и интерфейсов в C#

### Тема
Реализация коллекций и интерфейсов

### Цель работы
Изучить основные интерфейсы коллекций в .NET Framework, реализовать собственные коллекции и понять их контракты и функциональность.

### Изучаемые интерфейсы
*   **`IEnumerable`** — поддержка перебора элементов с помощью `foreach`
*   **`ICollection`** — базовые операции: добавление, удаление, подсчет элементов
*   **`IList`** — индексированный доступ, вставка и удаление по индексу
*   **`IDictionary<TKey, TValue>`** — словарь для работы с парами ключ-значение

### Реализованные коллекции

#### 1. SimpleList
*   **Расположение:** `src/Collections/SimpleList.cs`

*   **Реализуемые интерфейсы:**
    *   **`IList`** — основной интерфейс списка
    *   **`ICollection`** — базовые операции с коллекцией
    *   **`IEnumerable`** — перебор элементов

*   **Внутренняя структура:**
    *   Динамический массив объектов (`object[]`) для хранения элементов
    *   Начальный размер массива: 10 элементов
    *   Автоматическое увеличение размера в 2 раза при заполнении

*   **Основные методы и свойства:**
    *   `Count` — текущее количество элементов
    *   `this[int index]` — индексатор для доступа к элементам
    *   `Add(object value)` — добавление элемента в конец
    *   `Insert(int index, object value)` — вставка элемента по указанному индексу
    *   `Remove(object value)` — удаление первого вхождения элемента
    *   `RemoveAt(int index)` — удаление элемента по индексу
    *   `Clear()` — полная очистка коллекции
    *   `Contains(object value)` — проверка наличия элемента
    *   `IndexOf(object value)` — поиск индекса элемента
    *   `CopyTo(Array array, int index)` — копирование элементов в массив

*   **Особенности реализации:**
    *   Простая логика увеличения массива при нехватке места
    *   Использование базового массива объектов для совместимости
    *   Поддержка работы с `foreach` через `yield return`
    *   Проверка границ массива при операциях с индексами
      

#### 2. SimpleDictionary<TKey, TValue>
*   **Расположение:** `src/Collections/SimpleDictionary.cs`

*   **Реализуемые интерфейсы:**
    *   **`IDictionary<TKey, TValue>`** — основной интерфейс словаря

    
    *   **`IReadOnlyDictionary<TKey, TValue>`** — словарь только для чтения
    *   **`ICollection<KeyValuePair<TKey, TValue>>`** — коллекция пар ключ-значение
    *   **`IEnumerable<KeyValuePair<TKey, TValue>>`** — перебор пар

*   **Внутренняя структура:**
    *   Хеш-таблица с разрешением коллизий методом цепочек
    *   16 корзин (`buckets`) по умолчанию
    *   Использование связанного списка для хранения элементов в одной корзине
    *   Класс `Entry` для представления узла цепочки

*   **Основные методы и свойства:**
    *   `Count` — количество пар ключ-значение
    *   `this[TKey key]` — индексатор для доступа к значениям
    *   `Keys` — коллекция всех ключей
    *   `Values` — коллекция всех значений
    *   `Add(TKey key, TValue value)` — добавление новой пары
    *   `TryGetValue(TKey key, out TValue value)` — безопасное получение значения
    *   `ContainsKey(TKey key)` — проверка наличия ключа
    *   `Remove(TKey key)` — удаление пары по ключу
    *   `Clear()` — очистка словаря

*   **Особенности реализации:**
    *   Использование метода `GetHashCode()` для определения корзины
    *   Маска `0x7FFFFFFF` для получения положительных хешей
    *   Разрешение коллизий через связанные списки
    *   Поддержка перебора всех элементов через `foreach`

#### 3. DoublyLinkedList<T>
*   **Расположение:** `src/Collections/DoublyLinkedList.cs`

*   **Реализуемые интерфейсы:**
    *   **`IList<T>`** — основной интерфейс списка
    *   **`ICollection<T>`** — базовые операции
    *   **`IEnumerable<T>`** — перебор элементов

*   **Внутренняя структура:**
    *   Двунаправленный связный список с узлами
    *   Каждый узел содержит данные и ссылки на предыдущий и следующий узлы
    *   Хранение ссылок на голову (`head`) и хвост (`tail`) списка
    *   Внутренний класс `Node` для представления узлов

*   **Основные методы и свойства:**
    *   `Count` — количество элементов в списке
    *   `this[int index]` — индексатор для доступа к элементам
    *   `Add(T item)` — добавление элемента в конец списка
    *   `Insert(int index, T item)` — вставка элемента по индексу
    *   `Remove(T item)` — удаление первого вхождения элемента
    *   `RemoveAt(int index)` — удаление элемента по индексу
    *   `Clear()` — очистка списка
